### Featured Projects

* **[abb-irb120-vision-manipulation](https://github.com/xDarius1/abb-irb120-vision-manipulation)**  
  End-to-end autonomous vision-guided manipulation pipeline using ROS 2 Humble, Gazebo, and OpenCV. Features dynamic color thresholding, spatial moment targeting, and trajectory tracking via `ros2_control`.

* **[ufactory-xarm-storage-matrix](https://github.com/xDarius1/ufactory-xarm-storage-matrix)**  
  Industrial pick-and-place matrix storage and re-indexing pipeline for the uFactory xArm cobot. Interfaces active-low limit switches (CI 0–7) and real-time status LEDs (CO 0–5) with digital twin telemetry.
